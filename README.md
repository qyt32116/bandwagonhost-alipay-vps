### 支付宝付款时显示什么币种？

套餐页面通常以美元标价，例如 `$49.99/year` 或 `$19.99/month`。支付宝实际支付页面可能会显示人民币金额，换算金额以支付平台当时的汇率和页面结果为准。

不要直接用“美元价格乘一个固定汇率”估算最终付款金额。汇率会变化，支付页面也可能因为地区、税费或支付通道产生不同的最终金额。

比较稳妥的判断方式是：

- 先看 BandwagonHost 订单金额；
- 再看支付宝跳转页面显示的人民币金额；
- 最后确认支付页面的订单名称和金额一致。

如果支付宝页面没有打开、金额异常，或者付款后订单仍显示未支付，不要重复提交多次付款。先查看账户中的账单状态，必要时联系官方支持处理。

## 只想用支付宝买一个小 VPS，哪个套餐合适？

如果你的主要诉求是“可以用支付宝付款，同时买一台价格不高的 VPS”，不需要一开始就上高配方案。

20G KVM 配置为 1 GB 内存、20 GB SSD、2 vCPU，每月流量 1 TB，公开价格为 `$49.99/year`。它适合：

- 搭建个人博客；

1 GB 内存可以运行基础 Linux 环境，但安装面板、数据库、缓存和多个后台服务后，空间会很快变得紧张。这个套餐更适合愿意自己配置环境的人。

40G KVM 有 2 GB RAM、40 GB SSD、3 vCPU 和 2 TB 月流量，公开价格为 `$52.99/half year`。

## BandwagonHost 的 VPS 适合什么人？

BandwagonHost 的核心产品是自主管理型 KVM VPS，不是托管型主机。官方说明 VPS 使用 KVM 虚拟化，并通过 KiwiVM 控制面板管理实例，支持开关机、重装系统、紧急控制台、反向 DNS、数据中心迁移、快照、用量统计和 API 等功能。

它比较适合下面几类用户：

### 1. 想自己管理服务器的人

你需要能够处理：

- Linux 用户和权限；
- SSH 密钥；
- 防火墙；
- Nginx 或 Apache；
- PHP、Node.js、Python 等运行环境；
- 数据库备份；
- 系统更新和安全配置。

如果你希望服务商替你配置网站、修复程序、升级数据库，VPS 可能不是最省事的选择。

### 2. 需要完整 root 权限的人

这意味着你可以自由安装软件、调整系统服务和修改网络配置，但同时也意味着误操作的后果需要自己承担。删除错误目录、开放不必要端口、使用弱密码，都会把服务器暴露在风险中。

### 3. 需要灵活选择操作系统的人

官方页面列出了 AlmaLinux、Rocky Linux、CentOS、Debian、Ubuntu、CentOS Stream 和 Fedora 等系统选项，同时还支持其他可启动 ISO。

如果你已经有固定的 Linux 部署习惯，选择余地比较大。新手则建议优先使用当前仍有长期支持的稳定系统，不要因为系统名称看起来“更新”就盲目选择。

## 支付宝付款后，订单没有立即开通怎么办？

VPS 通常支持即时开通，但“即时”不等于每个订单都能在几秒内完成。可能影响开通速度的因素包括：

- 支付状态尚未同步；
- 订单触发人工审核；
- 所选数据中心暂时缺货；
- 支付平台回调延迟；
- 账户信息需要验证；
- 订单本身没有完成付款。

可以按下面顺序排查：

1. 登录 BandwagonHost 客户中心，查看账单是否已经标记为已支付。
2. 检查邮箱中是否收到订单确认或服务开通通知。
3. 确认支付宝账单状态是“支付成功”，而不是仅仅显示处理中。
4. 检查订单中的服务状态和数据中心。
5. 不要马上重复支付相同订单。
6. 如果长时间没有变化，再提交支持工单。

官方知识库说明，退款会退回原始付款方式；退款申请还受到新订单、购买时间、账户状态、流量使用量和服务条款等条件限制。

换句话说，买 VPS 前不要把“30 天退款”理解成无条件试用。官方条款列出了多项条件，包括新订单、购买不超过 30 天、账户没有违规、月度流量使用低于配额的 10% 等。

## 续费可以用支付宝吗？

续费是否能使用支付宝，要看续费账单页面当时提供的支付方式。BandwagonHost 的续费流程并不是传统意义上的自动扣款模式。

官方说明：

- 系统会在续费日期前生成新的账单；
- 如果账户有足够余额，余额可能被用于支付；
- 如果账户余额不足，需要手动支付到期账单；
- 平台不会自动扣除用户保存的信用卡或 PayPal 支付方式；
- 用户可以在客户区修改未来的计费周期。

因此，如果你使用支付宝购买年付或半年付套餐，建议把续费日期记在自己的日历里。不要等到服务已经暂停后才处理账单，尤其是运行网站、代理服务或 API 的 VPS。

## 选择 BandwagonHost 时不能忽略的限制

支付宝能付款，只解决了购买环节的一部分问题。真正影响长期使用的，还是服务器管理和服务限制。

### 自主管理意味着没有完整运维托管

BandwagonHost 官方定位是 self-managed VPS。服务商负责底层节点和网络基础设施，但不会替你维护网站程序、修复应用报错或配置业务系统。

### 流量用完后不是无限加价

官方 FAQ 说明，当 VPS 超出月度数据传输额度时，不会按超额流量自动收费，而是可能被暂停到当月结束，用户可以升级方案。

所以不要把“不会产生超额账单”理解成“流量可以无限使用”。如果你的项目有大量图片、视频、下载文件或备份流量，应该提前估算月度传输量。

### SLA 不一定适用于所有套餐

BandwagonHost 的 SLA 页面说明，服务等级协议只适用于明确标注包含 SLA 的套餐或服务，并不是所有 VPS 默认都享有相同的 SLA 条款。

如果你的业务对可用性有硬性要求，购买前要确认具体套餐是否明确包含 SLA，以及服务中断时可获得的补偿形式。SLA 补偿通常是服务时间抵扣，并不等同于现金退款。
